Hoja de Fórmulas Permitida en la Prueba (5° Año E.S.T.P.)

1. Fórmula Resolvente de Bhaskara (Grado 2)

Para todo polinomio cuadrático P(x) = a·x² + b·x + c (con a ≠ 0):

x₁,₂ = [ -b ± √(b² - 4·a·c) ] / (2·a)

Una vez halladas las raíces x₁ y x₂, la forma factorizada es:

P(x) = a · (x - x₁) · (x - x₂)

¡Atención! Nunca olvides escribir el coeficiente principal "a" multiplicando adelante.

2. División de Polinomios y Regla de Ruffini

Algoritmo de la División Entera: Dados P(x) y D(x), existen únicos Cociente C(x) y Resto R(x) tales que:

P(x) = D(x) · C(x) + R(x)

Regla de Ruffini y Teorema del Resto: Se aplica cuando el divisor es de la forma (x - r). El resto coincide con evaluar R = P(r). Si R = 0, la división es exacta.

3. Factorización de Polinomios de Grado 3 o Superior (División por Ruffini + Bhaskara)

Para factorizar P(x) = a·x³ + b·x² + c·x + d conociendo una raíz x₁ (o un factor divisor (x - x₁)):

  1. Dividimos P(x) ÷ (x - x₁) aplicando la Regla de Ruffini (verificando que el resto sea 0) para bajar un grado y obtener el cociente cuadrático C(x) = a·x² + b'·x + c'.
  2. Aplicamos la Fórmula de Bhaskara al cociente C(x) para hallar las dos raíces restantes x₂ y x₃.
  3. Escribimos el polinomio completamente factorizado: P(x) = a · (x - x₁) · (x - x₂) · (x - x₃).
